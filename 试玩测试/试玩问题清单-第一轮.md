# 红缘大冒险 试玩问题清单（第一轮，独立测试）

测试方式：把试玩版（Godot Web 导出，v4.7.2）下到本地，用浏览器按竖屏 390×844 逐屏操作，触屏事件输入。
**覆盖范围：序章 → 第一章（街边、驾驶、停车场）。第一章停车一步没能通过，后面章节（成都、来电、静冈、海南、香港、终章）没有进入，不下结论。**
说明：测试用软件渲染，约 17～20 帧，只用于判断逻辑和版式，不评价流畅度。输入是模拟触屏，停车一步可能有我没摸到的操作，见 P0-2。

## 一、阻塞/无响应（优先修）

**P0-1 街边"上车"没有任何引导，玩家会以为卡死。**
- 现象：第一章开场只有顶部一行淡淡的提示"开着那辆紫色的车，去东方明珠下转转吧"。点车、点地面、点提示都没反应。人物走到车旁边也没反应，我试了约 15 次才发现。
- 原因：互动手形图标只在人物脚下走到热点目标点（约 360×640 设计坐标的 263,432）很小的范围内才出现，没有走位提示，也没有点击车子自动走过去。
- 建议：点车/点热点时人物自动走到目标点并触发；或者热点范围加大；热点上要有常驻的闪烁提示。
- 截图：`截图/02-第一章街景.jpg`

**P0-2 停车一步走不完，停车场无限循环。**
- 现象：到东方明珠后，右侧停车场（黄框高亮车位）一直循环滚动，上面的进度条已满，一直没结束。车横向被锁在右车道（x 约 2x 屏 520），始终够不到右侧车位（x 约 610～770），也就是车位在车能到的范围外。我试了向右拖、按住不放、点击车位，都没有进展。
- 设计文档写的是"按住减速、松手停下，停歪自动摆正"，实际画面上没有任何文字或图标告诉玩家该怎么做。
- 建议：停车阶段加一句操作提示；车位要落在车能走到的范围内；进度条满了就该自动进入停车阶段，不要无限循环；设一个保底，几秒无操作自动入位。
- 截图：`截图/06-停车场.jpg`、`截图/07-停车卡住.jpg`

## 二、比例问题

**S-1 人物与场景比例随位置跳变。** 同一场景里，人物在车旁约 80px 高（紧贴车身，与车高差不多），走到前景人行道后变成约 90px。透视缩放是有的，但站在车前时人比车还高，和"车停在路面、人在路沿"的纵深对不上。建议统一一条"脚点 y → 缩放"曲线，并在街景底图里按这条线校对车和人的比例。截图：`截图/02-第一章街景.jpg`、`截图/03-互动手形遮挡人物.jpg`
**S-2 驾驶画面里车偏小。** 俯视图里主角车约 45×75（屏幕 css 像素），整条路 3 车道，车占不到一个车道宽的 2/3，显得空，和街景里那辆大车（G42）在体量感上不一致。
**S-3 熊猫园一屏**（本轮没有走到，没能核对）：用户之前反馈"人物偏小、胖白粗糙"，建议开发线程自查，不在本次结论内。

## 三、对话框、文字

本轮只看到**序章**一处对话框（`截图/01-序章请柬.jpg`），其余章节对话没能进入，所以固定位置/靠边的一致性没法下结论，现状如下：
- D-1 序章对话框：宽约占屏幕 87%，左右各留约 25px，贴近底部，但 y 位置在 1x 屏约 565～720，其上方的"打开看看"按钮在顶部（人物、桌面、信纸之间），按钮离标题和请柬都很近，层次乱，标题"红缘大冒险 2.0"字号过小，几乎看不见。
- D-2 文字换行：序章两行"帮阿鱼把剩下几样东西找齐嘛～ / 找齐了这封请柬就能寄了"没有标点掉行首。
- D-3 **第一章顶部章节标题和提示直接叠在亮色天空上**，没有底板，白字对比度很低（尤其"去东方明珠下转转吧"在云上几乎看不清）。而序章是带边框的米色对话框，两种文字样式不统一。建议所有旁白、提示、对话统一用一个固定位置和尺寸的对话框。
- D-4 第一章开场的旁白文案（A1-1a "七月的上海，阳光依然炎热"）在章节 JSON 里有，实际运行里没看到，直接就是章节标题加提示，叙事出现了丢失（见第五节）。

## 四、画面与交互细节

- V-1 **互动手形图标盖在人物身上**（`截图/03-互动手形遮挡人物.jpg`）：图标放在车的中心，正好遮住人物上半身，应该放到人物头顶上方或者车上方。
- V-2 **虚拟摇杆没有视觉反馈**：左下摇杆按下、拖动时，旋钮一直停在中心，不跟着手指，玩家不知道自己有没有推到。
- V-3 **人物没有碰撞**：街边走到车上能直接穿过去，路边的隔离桩链条也能穿。
- V-4 **驾驶画面**（`截图/04-驾驶起始.jpg`、`截图/05-车辆重叠无碰撞.jpg`）：
  - 画风硬切：第一章街边是像素写实插画风，驾驶一下变成平涂的俯视图，草地是纯色，风格和透视（斜侧视 → 正俯视）都对不上。
  - 车辆精灵带一圈半透明深色方块底（阴影方框），在路面上很显眼。
  - 车辆相撞会直接重叠穿过，没有任何碰撞反馈（设计只"减速"，但画面上完全看不出来）。
  - "出发！"按钮压在车道线上，进度条没有标签、起终点两个圆点没有说明。
  - 底部有一个常驻的圆形触点（疑似触摸提示/摇杆），没有说明作用。
- V-5 **停车场是一块贴上去的矩形**：右上角浮在人行道和草地上，边缘切到树，没有衔接（`截图/06-停车场.jpg`）。

## 五、段落衔接（重点，对应"故事碎片化、没有链接感"）

每一条是"从 A 到 B"，我看了什么、缺什么：

| 衔接 | 现状 | 缺什么 / 建议 |
|---|---|---|
| 序章请柬 → 第一章 | 点一下对话框就直接切到街边，没有过渡。请柬说"帮阿鱼把剩下几样东西找齐"，下一屏只出现章节标题，没有"先去趟上海"（文案 A0-3 在包里，但没看到显示）。 | 玩家不知道为什么到上海、"回忆视角：阿鱼"也没出现。请柬→街边应有一段交代（A0-3 + 回忆视角字幕），并且人物从请柬桌面"走进"回忆。 |
| 第一章开场 → 上车 | 有提示句，但没有旁白交代时间地点（A1-1a/b）。 | 补上"七月的上海"旁白；点热点要自动走过去。 |
| 街边 → 驾驶 | 点手形后直接硬切到俯视图，没有上车动作、没有淡入淡出，人物和车一下消失。 | 加上车动作 + 转场；驾驶开始前给一句"开去东方明珠"。 |
| 驾驶 → 停车场 | 路上景物平淡，没有任何东方明珠的远景；停车场突然从右边滑出，一个粉色塔形小图标，没有提示。 | 路上要看到东方明珠越来越近；到达前有"快到了，靠右停"提示。 |
| 停车 → 遇到阿晓 | 未通过，没能看到。 | 同上，P0-2 修完后复测。 |
| 全局 | 每段画风、字体、对话样式、操作方式都不同（照片式插画 / 平涂俯视 / 米色对话框 / 无框白字）。 | 需要一条全局"叙事线"：每章开头固定的时间地点卡，每章结尾固定的"下一站"卡，还有统一的视觉模板，才会让玩家觉得是一个故事。这条建议同时影响美术统一待办。 |
