## 一、核心规则：工位之间靠仓库里的看板交接，不靠阿鱼传话

几个工位是各自独立的对话，互相听不见。所以：

- 所有派活、交接、判过、退回，都写在仓库里的 **`回执/W2工位/看板.md`** 这一个文件里。
- **阿鱼只跟 D1 说话**（阿鱼 11/05 定）。D1 是总调度：接阿鱼的话，转成看板上的卡，派给 D2、D3、D4，并负责叫醒它们干活、催进度、收结果。
- D1 用平台能用的方式直接驱动其他工位，比如调用、子任务、发消息。如果平台做不到让 D1 叫醒别的工位，D1 要第一时间如实告诉阿鱼，并给出最省事的替代办法，不许假装已经派出去了。
- Astra（D2）仍然是游戏本身的负责人：玩法、画面、手感由它决定。D1 只管调度、守原稿和对外，不改 D2 的设计决定。
- 每个工位被叫醒后，先 `git pull`，读看板，做自己名下的卡，做完更新看板再 `git push`。

**审美验收**（阿鱼 11/05：不许交丑东西）：画面好不好看，也要按资深游戏策划和美术的标准来判。
- **谁判**：D4 主判，D1 复看。画图的 D3 和做界面的 D2 不能判自己的东西。
- **怎么判**：每次交付前，把所有屏幕截图拼成一张，跟风格样板放在一起看，再跟两三张成熟的星露谷式商业游戏截图并排对比。对比图只用来判断，不许放进游戏。逐条看：
  1. **构图**：主体清楚、视线有焦点、不歪不挤，画面里没有大块空白，也没有大块纯色。
  2. **配色**：和谐温暖，用同一套调色板，没有刺眼的颜色或脏灰色。
  3. **层次**：前景、中景、背景分得开，人物和可互动的东西能一眼看到。
  4. **精致度**：边缘干净，没有糊、没有锯齿错位，没有白边，没有拉伸变形。
  5. **一致性**：和风格样板是一个画风，人物、场景、界面像同一个画师画的。
  6. **整体感觉**：放进应用商店的截图里，看起来像一款成熟的商业游戏，而不是原型或网页。
- **反面例子**（阿鱼 11/05 截图）：成都转深夜那一屏，整个场景上盖了一块大的半透明磨砂框，框里什么都没有，下面只有一个对话框写着日期。这就是丑：遮住了场景，又是空的，还像网页弹窗。转场应该用游戏画面本身来做，比如天色渐暗、镜头推近、淡出到深夜房间，不许用大块半透明面板盖住画面。
- **新画的东西必须和现有同类素材并排比**：新人物和现有人物排在一起，新道具和现有道具排在一起，都用原尺寸，再放大 2 倍各看一遍。精度明显不如现有的（比如没有五官、衣服是平涂、描边粗糙），直接判不过。宾客 07 号 R1 就是反面例子，它本来应该在 D4 和 D1 这里就被拦下。
- **审美验收从现在起立即执行**，包括已经交过的图：D4 把目前所有新画的素材按这一条重新过一遍。
- 任何一条不过，就直接判「退回」重做，写清是哪一屏、哪一条、怎么改。**不许以「能用」「先凑合」放行。**

**不许中途停工**（阿鱼 11/05）：每个工位在结束一次回复之前，都要先对照看板自查一遍：
- 自己名下还有「待做」或「退回」的卡，并且没有被别的事卡住，就**接着做**，不要停下来汇报，也不要问「要不要继续」。
- 只有三种情况可以停：
  1. 名下的卡全部做完，已经改成「待判」或「通过」。
  2. 真被卡住了，在看板上写明卡在哪里、在等谁。
  3. 周额度剩 20%。
- 停的时候用一句话报进度：做完了哪几张卡、还剩哪几张、下一步做什么。
- D1 每次被叫醒都要检查各工位有没有半途停下；发现有人停了，马上把它叫醒，让它接着做。

**自己补画面**：场景里需要过渡画面、空镜头、转场之类的东西，Astra 直接用游戏里现有的画面补上，比如镜头平移、淡入淡出、请柬特写，不用请示。

**额度**（阿鱼 11/05 定）：整个小组的周额度剩 20% 时全部停手。停手前把手上的东西提交推送、更新看板，再由 D1 告诉阿鱼做到哪里、还差什么。快到 20% 时，先保证有一个能玩的包推上去。

**D0 小助手**：不进工作流程，删掉或闲置。阿鱼有任何事都只找 D1。


## 八、素材还原：照村子的做法来（阿鱼 11/05：还原太差）

D1、D3 开工前先读这几份，把村子里已经验收过的做法用到爱情篇：
- `godot/docs/任务卡-A05至A09-出图总则.md`
- `godot/ASSETS.md`（第 1 节瓦片、第 14 节分层场景）
- `godot/ayu_home/v4/ART_SOURCES.md`

要搬过来用的做法：
1. **先锁风格锚点，再出图**：村子先由阿鱼拍板一张风格锚点，之后所有图都对着它画。爱情篇就用 `回执/W2工位/风格样板.png`，再加上人物设计一览图。
2. **定死比例尺**：人物高多少像素、门和桌子多大，写成数字。所有图按这个比例画，**原尺寸使用，不放大缩小**。
3. **生成时写清像素规格**：照吉他角的做法，在提示词里写明低分辨率网格、每种材质 3～4 个色阶、硬边阶梯轮廓，不要抗锯齿、柔光和写实细纹。生成后再按网格做减色和描边。
4. **会挡住人的东西做成积木**：树、桌、栏杆这类单独出图，带脚点，不画进底图。
5. **还原原素材时并排对比**：画阿鱼、Toretto、G42，或者宾客这类已有角色时，把新图和原图并排，五官、服装、配饰、颜色逐项对齐。对不上就不交。
6. **每张图都记来源**：在 `manifest.json` 写明来源、生成了第几次、是否通过；没通过的版本也保留。
