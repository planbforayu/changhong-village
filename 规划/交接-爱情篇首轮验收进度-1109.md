## 出网页包并发布到 GitHub Pages
1. 备份 `godot/export_presets.cfg`，把 Web 预设的 `export_files`（第二个）替换成「微信可达的素材加非素材项，去掉含 `/_inbox/` 的」。
2. 临时把 `hongyuan/tools/export_web.py` 里 `sync_export_files` 那行改成 `pass`。
3. `python3 export_web.py <输出目录> --godot <godot 路径> --user-data-name hongyuan_review_1108 --content-base-url ./content/`
4. 还原 export_web.py 和 presets。
5. `python3 pages_site.py <输出目录> <love_in_su7 本地仓库> <提交号>`，然后在 love_in_su7 里提交并推送 main。
6. 冒烟测试：用浏览器打开，检查开屏进度条走完、能进序章。
