## 一、游戏是什么

《苏七镇奇缘》是阿鱼的个人非商业小游戏，准备发布成**微信小游戏**，同时有一个**网页版**给朋友试玩。整部游戏分三篇，玩家一路走下来：

| 篇 | 内部叫法 | 玩家体验 | 首发要求 |
| --- | --- | --- | --- |
| 爱情篇 | 红缘大冒险 | 收到一封没写完的请柬，跟着主角走过上海、成都、来电、静冈、海南、香港六章回忆，每章收集请柬的一部分，终章写下名字、封口寄出 | **完整、打磨好**，是验收重点 |
| 山庄篇 | 罗曼山庄 | 以宾客身份入席婚宴：签到、入座、给新人写悄悄话 | 首发只要求现有宴会厅能坐下、能写悄悄话 |
| 村子篇 | 裳泓村 | 婚宴后回到村里安家：进屋、种地、做小事，可以一直自由玩 | 首发只要求能从宴会厅出门进村、自由逛 |

主线顺序：

```
序章（打开请柬）→ 上海 → 成都 → 来电 → 静冈与静安 → 海南 → 香港
→ 终章（写名字、封口）→ 入席罗曼山庄宴会厅 → 回到裳泓村的家
```

几条不能碰的底线：

- **故事不许自己编**。剧情和对白以 `docs/红缘原稿/` 里阿鱼给的定稿（v1.8、v1.9、全量文案 v1.1）为准。
- 游戏里地名一律写「苏七镇」。
- 小游戏**没有失败、没有分数**，失误只会重来一次；不做章末卡、领奖页、选章页。
- 前六章旁白不用第一人称；画面上不出现系统词。
- 没有付费、充值、对战和排名。

## 三、技术栈和出包

| 项 | 用什么 |
| --- | --- |
| 引擎 | Godot 4.7.2，兼容渲染模式（为了和微信、网页一致） |
| 代码 | GDScript；章节内容是 JSON 数据驱动 |
| 美术 | 像素风（星露谷式温暖像素），图由 GPT 画，规格按 `godot/ASSETS.md` 和 `回执/W2工位/规格-统一比例尺与画风.md` |
| 网页版 | Godot Web 导出 → 按章拆包 → 发布到 GitHub Pages |
| 小程序 | godot-minigame 插件导出微信小游戏；主包必须小于 4 MB，大图和音频放微信云存储按章下载 |
| 测试 | `godot/hongyuan/tests/run_all.sh`（无显示器时自动用 xvfb-run） |

### 出包流程

- **网页版**：`godot/hongyuan/tools/export_web.py` 导出，`split_web_pack.py` 按章拆包，`pages_site.py` 生成 Pages 站点后推到 `love_in_su7`。现在打开只先下 3 MB，序章时后台预下载上海，终章时预下载婚礼现场；村子约 170 MB，点「去村子」时才下载。
- **小程序**：在阿鱼的 Mac 上跑 `godot/hongyuan/tools/export_wechat.py`（用法见同目录 `WECHAT.md`），会分出「小游戏目录」和「云目录」。云目录里新增的 `.bin` 由阿鱼上传到云存储，然后在微信开发者工具里导入小游戏目录、出预览码。上传体验版前要先在真机从序章走到进村。
- **微信里的坑**：不能从显卡读回数据（`get_image`、`surface_get_arrays` 等会让微信直接崩，电脑上测不出来）。发版前按 `godot/README.md` 里那条 grep 查一遍。

### 新图接进游戏的注意点

- 新图放进 assets 后先跑一次 `godot --headless --import`，否则场景里不显示。
- `_inbox` 里的 `.import` 不要提交。
- 导出网页时要排除 `ayu_home/*`、`hongyuan/assets/_inbox/*`，否则包会超过 256 MB（按章拆包后由脚本处理）。
- 换背景时检查可走区域、热点和站位，旧人物会叠在新图上。

## 六、新人从哪下手

1. 读本文件和 [项目节奏表.md](项目节奏表.md)。
2. 读你所在组的看板：爱情篇 `回执/W2工位/看板.md`，山庄 `回执/山庄收尾/看板.md`，村子看 `回执/样板推广-1109/` 和 `给Astra任务书/`。
3. 读 `docs/红缘原稿/`，知道故事是什么。
4. 写代码的：
   ```sh
   git fetch origin hongyuan-launch
   git checkout -b <你的短分支> origin/hongyuan-launch
   cd godot && godot --headless --import
   GODOT=godot ./hongyuan/tests/run_all.sh
   ```
   先跑一遍测试，记下主线原本就失败的项，之后只看有没有新增失败。
5. 画图的：读 `规划/给GPT-出图清单与规范-1108.md` 和 `回执/W2工位/规格-统一比例尺与画风.md`，从清单最前面没做的序号开始。
6. 先打开网页版完整玩一遍，比读任何文档都快。

### 不要做的事

- 不要在 `hongyuan-launch` 上直接提交，也不要往旧分支上提交。
- 不要自己编剧情、改对白。
- 不要提交密钥、AppSecret、账号信息；上传、部署、改小游戏后台、花钱之前要阿鱼点头。
- 不要删别人的文件；共享文件夹只加不删。
