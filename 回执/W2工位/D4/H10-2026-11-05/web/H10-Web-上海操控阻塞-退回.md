## 体验路径与复现

1. 从冻结目录启动 `index.html`，等待 Godot 加载完成。标题页可见「打开看看」按钮及未完成请柬提示。
2. 进入第一章「缘分的起点—BMW G42」。画面文字要求开阿晓的紫色车去东方明珠下转转；人物、车辆和左下角半透明摇杆均可见。
3. 保持视口 360×640，在左下角摇杆向右拖动；再点击步道地面和车辆。观察人物、车辆、场景目标及声音反馈。
4. **实测：** 下面五次输入探测均无移动或互动反馈。重新以 iPhone UA、360×640、3倍像素比复测一次摇杆拖动，结果仍相同。

| 输入探测 | 操作 | 实测 |
| --- | --- | --- |
| 1 | 左下摇杆短拖向右 | 人物与车辆位置不变，无动作/声音反馈 |
| 2 | 点击紫色车辆驾驶位附近 | 未上车、未触发互动 |
| 3 | 在摇杆上按住约 1.2 秒 | 人物与车辆位置不变，无反馈 |
| 4 | 左下摇杆较长拖向右 | 人物与车辆位置不变，无反馈 |
| 5 | 点击可走步道地面 | 人物未走向落点，无反馈 |
| 复核 | 切换 Safari iPhone UA，设 360×640、3倍像素比后再次拖动摇杆 | 结果仍相同 |

以上是输入探测，不等于完成了玩法五轮。由于基本移动没有进入，上海驾驶/停车玩法无法实际开始；钓鱼、坐席、套圈、烟花、拖行李、火漆等玩法也都没有用此包体验。

## 退回原因、修复要求与复验步骤

- **原因：** 360×640 下最基本的移动输入没有效果，玩家无法按第五节要求走路、靠近并亲手触发剧情点。当前候选不能继续验收章节玩法。
- **D2 修复要求：** 核清 Web 移动端实际接收的输入事件；让左下摇杆和点地两种走法都可用，并保证进入/使用车辆或互动后有即时可见反馈。请提供新冻结包、完整源码提交、包 SHA-256 和独立入口。
- **复验步骤：** 新档从标题进入序章；分别用摇杆和点地在 walkArea 移动；走到车辆附近亲自互动；连续完成上海驾驶/停车各五次，五条标准逐次记录；再刷新并回归 K01–K04。任何一次仍是无响应或「点一下就切下一页」都退回。
- **微信：** 此轮没有微信预览包或二维码，微信开发者工具当前登录状态 `login:false`；微信端未判，不与 Web 结果混记。
