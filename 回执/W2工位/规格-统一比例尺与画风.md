# 规格：统一比例尺与画风（爱情篇全篇）

阿鱼 11/07 意见：「还原的比例不对，这样的问题比较多」「路人和主角画风肯定要统一」。
本规格适用于全部 8 章，所有组都要遵守。检查工具是 `godot/hongyuan/tools/check_scale.py`。

## 一、为什么会不对

1. **只有人按远近缩放，物件没有共用一把尺。** `world_scale.gd` 只给「人」做了景深标定。`actors` 里的车、门、道具用的是手调的 `scale`（等于人高的几倍），没有和真实尺寸挂钩。例如上海街景的 G42，`scale=0.7`，画出来相当于 1.15 米高的车。
2. **背景图里画死的物件和人不是同一把尺。** 以上海街景为例，背景里停着的紫车、栏杆，按人的标定只相当于 0.7 米左右，路灯却又是正常的 4 米多。同一张背景内部的比例就不一致。
3. **透视混用。** 停车场一段把俯视的 `g42_top.png` 放进正视场景，人是正面，车是从天上看的。
4. **画风割裂。** 路人（罗曼山庄宾客图）的头身比、描边粗细和配色，和主角阿鱼、Toretto 不一样。

## 二、统一规则（全篇一起改）

**R1 一把尺。** 场景里任何站在地面上的东西，画出来的高度一律按下式计算：
`person_height_at(脚下 y) × 真实高度(米) ÷ 1.65`。
人是 1.65 米的基准：阿鱼约 1.62，Toretto 约 1.80，路人在 1.55～1.85 之间。

**R2 真实尺寸表。** 新素材进游戏前，先在 `check_scale.py` 的 `REAL` 表里登记它在画面中可见部分的真实高度：

| 物件 | 高（米） | 备注 |
|---|---|---|
| 成年人站姿 | 1.55～1.85 | 坐姿 × 0.844（`pose_ratio`） |
| 轿车（侧/前视） | 1.45 | 车长约 4.7 米，约为人高的 2.8 倍 |
| 门 | 2.1 | 机场出口门约 2.4 |
| 路灯 | 4.0 | |
| 栏杆 | 1.1 | |
| 长椅座面 | 0.45 | 靠背顶约 0.9 |
| 行李箱（登机箱） | 0.55～0.65 | |
| 熊猫（坐） | 0.8 | |

**R3 一个场景只用一种透视。** 正视或 3/4 视角的场景里不准出现俯视贴图（`*_top.png`）。俯视贴图只留在开车小游戏本身里用。

**R4 背景标定以背景里的车和门为准。** 每张背景要先量出背景里画好的车或门，再按 R2 反推 `world_scale.PROFILES` 的两组数值。如果同一张背景里，车、栏杆、路灯三者按 R2 量出来的人高相差超过 15%，就说明这张背景本身比例不一致，要退回美术重画，不能靠代码硬凑。

**R5 画风统一（阿鱼已定）。** 以现有主角的画风为准，所有路人重画成同一画风。具体要求：
- 头身比、描边粗细、像素密度、配色饱和度都和阿鱼、Toretto 一致。
- 体型在 1.55～1.85 米之间，有高有矮，男女老少都要有。
- 每个人都要有行走四帧和静止帧。
- 同一张脸在全篇最多出现两次。

山庄宾客图也照此要求处理，与 #71 的规则一致。

**R6 自动检查。** 每次提交前运行 `python3 godot/hongyuan/tools/check_scale.py --strict`，必须是 0 个问题。背景内部的比例代码量不了，所以每章的验收截图里，要把车、门和人放在同一排对照，人工核一次。

**R7 空间要说得通（阿鱼 11/07：「这种莫名其妙的东西不要出现」）。** 任何图进游戏前，都要逐条检查下面几项，任一项不过就退回重画，不进包：
- 门、窗必须装在墙或门框上，不能独立立在草地或空地中间。
- 人和物件必须落在同一个地面上，脚下有接地影子。不能悬空，也不能和别的东西穿插。
- 室内和室外之间要有清楚的分界（墙、门洞、台阶）。室内的窗帘、灯、地砖不能直接拼在草坪上。
- 同一画面只有一个光源方向，阴影都朝同一边。
- 每一样东西都要说得出它是什么、为什么在那里。说不清的就删掉。
- 反例：终章开门图里，两扇中式门没有墙和门框，立在草坪中间；门槛木梁悬在草地下沿；前景是室内地砖，后面却是室外花园。

验收时，美术组交图要附一句「这是哪里、人站在哪、门开向哪」，由 Claude 按本条逐项判定。

**R8 男女主角任何画面都要认得出是同一个人，肢体必须正常（阿鱼 11/07）。**

标准形象（以 `w2/common/ayu_walk_front_*`、`toretto_neutral_r2.png` 为准）：
- **阿鱼**：黑色长直发，有齐刘海，皮肤偏白，脸型圆。日常穿白色短 T 恤、黑色阔腿裤、黑白球鞋。换装（婚纱、旗袍、泳装、温泉）只换衣服，发型、脸、肤色、头身比都不变。例外：静冈篇的双马尾是阿鱼确认过的造型，可以保留。
- **Toretto**：黑色短碎发，**任何画面都戴圆框眼镜**。日常穿白色 T 恤、黑裤、黑白球鞋。换装同样只换衣服。

逐张检查的项目，任一项不过就退回重画：
1. 两只手、两只脚，每只手都连着肩膀，没有多出来或飘着的手脚，也没有断肢。
2. 拿着的东西（笔、鱼竿、泳圈、行李箱）要握在手里，手的数量不能因此变多。
3. 关节方向正常，坐姿的膝盖要弯、屁股落在座面上。
4. 发型、发色、眼镜、肤色和标准形象一致。
5. 头身比和标准形象一致，全身立绘和插画 CG 都按同一个头身比。
6. 分层拼接的图（身体图加手臂图）合起来后，只能看到两只手。

走查分两步：一是逐张看静态图（下面的对照表）；二是每次出包后，在实际游戏里把每个场景截一张图，看叠在一起的效果（身体加手臂、人加道具、人加背景）。第二步由 Claude 在每次出包后完成，再交给阿鱼。

静态图的走查方法：运行 `python3 godot/hongyuan/tools/char_sheet.py 输出.png`，把全部主角图拼成一张对照表，和标准形象逐张比对。插画 CG（有男女主角出现的背景、回忆图）也要单独拼一张对照。交图时附上对照表。

## 四、做到什么程度算过

- `check_scale.py --strict` 结果为 0。
- 8 章每个可走动的场景各出一张截图，主角、路人、车（或门）同时在画面中，三者比例肉眼看不出别扭。
- 路人和主角并排站时，看不出是两套画风。
- 没有俯视物件混在正视场景里。
- 主角对照表逐张通过 R8：多手、断肢、少眼镜、换发色都没有。
- 全篇每张图都过了 R7，没有悬空的门、穿插的物件，也没有室内室外硬拼。
