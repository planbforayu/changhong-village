## 第一部分：标准规范（每张图都要过）

### 1. 画风
- **星露谷那种像素马赛克风**（阿鱼已定）。上海那部分现在的画风是参考基准。
- 不要平涂纯色、不要平滑卡通、不要 Q 版大头。
- 插画 CG 和游戏立绘用**同一个头身比**，不能一个精细大头、一个小人。

### 2. 主角形象（规格 R8，任何画面都要认得出）
- **阿鱼**：黑色长直发、齐刘海、皮肤偏白、圆脸。日常白短 T、黑阔腿裤、黑白球鞋。换装只换衣服。**例外：静冈篇双马尾保留。**
- **Toretto**：黑色短碎发，**任何画面都戴圆框眼镜**。日常白 T、黑裤、黑白球鞋。
- 标准参考：`w2/common/ayu_walk_front_*`、`toretto_neutral_r2.png`、`round1/people/*`。
- 肢体：两只手两只脚，都连在身上；拿的东西握在手里；坐姿膝盖弯、屁股落在座面上；分层图（身体 + 手臂）合起来只能看到两只手。

### 3. 比例（规格 R1、R2）
以 1.65 米的人为基准换算。常用真实高度：

| 物件 | 高（米） |
|---|---|
| 成年人 | 1.55～1.85（阿鱼 1.62，Toretto 1.80） |
| 轿车侧/前视 | 1.45（车长约人高 2.8 倍） |
| 门 / 机场出口门 | 2.1 / 2.4 |
| 路灯 | 4.0 |
| 栏杆 | 1.1 |
| 长椅座面 / 靠背顶 | 0.45 / 0.9 |
| 登机箱 | 0.55～0.65 |
| 熊猫（坐） | 0.8 |

同一张背景里，车、栏杆、路灯按上表量出来的人高相差不能超过 15%。

### 4. 透视（规格 R3）
一个场景只用一种透视。正视或 3/4 视角场景里不能出现俯视图。俯视图只用在开车小游戏本身。

### 5. 空间说得通（规格 R7）
- 门窗必须装在墙或门框上，不能立在空地上。
- 人和物件落在同一个地面，有接地影子，不悬空、不穿插。
- 室内室外有清楚分界，不能把室内地砖拼在草坪上。
- 一个画面只有一个光源方向。
- 每样东西说得出是什么、为什么在那，说不清就删。

### 6. 路人（规格 R5）
- 头身比、描边、像素密度、饱和度和主角一致。
- 1.55～1.85 米，男女老少都有。
- 每人有行走 4 帧 + 静止帧。
- 同一张脸全篇最多出现两次。

### 7. 尺寸和交付
- 可探索场景底图改成 **9:20 竖屏高图**（阿鱼已定），宽度沿用原图，多出的高度用来上下拖动镜头。
- 文件名沿用原文件名；新图用下面清单里给的名字。
- **每张图附一句：这是哪里、人站在哪、门开向哪。**
- 主角图交一张对照表（`python3 godot/hongyuan/tools/char_sheet.py 输出.png` 拼出来的），和标准形象并排。
- 不画商标：香港乐园去掉米奇头、星形球等，看得出是乐园就行（阿鱼 11/08 已定）。

## 第三部分：交付方式

0. **本地已经画好的图先全部推上来（11/08 阿鱼）。** 不用先改，原样推到 `art/love-1108`，放进 `godot/hongyuan/assets/` 下对应路径（不确定放哪就放 `godot/hongyuan/assets/_inbox/`）。同时在分支根目录加一份 `回执/爱情篇/GPT已有图-清单.md`，每张图一行：文件路径、画的是什么、对应本清单哪个编号（对不上就写「清单外」）。Claude 会先核对这批图，再告诉你哪些能用、哪些要改、清单还缺什么。

1. 先交一份**自查表**：第二部分每一行写「可用 / 小改 / 重画 / 新画」，自己发现的新问题也写上。
2. 图按 A、B、C 分组交，每张附「这是哪里、人站在哪、门开向哪」一句。
3. 主角图附对照表。
4. **推到仓库分支 `art/love-1108`**（`bardayu-cpu/changhong-village`），图放在 `godot/hongyuan/assets/` 下对应路径。**每做好一批就推一次，不用等全部做完**，第一次推送时开一个 PR，标题「爱情篇出图 1108」，后面的批次继续推到同一个分支。PR 描述按本清单编号逐条写「已改 / 没改及原因」。
5. Claude 收图后验收：能用的直接接进游戏，不过的按编号退回再改。

**优先顺序：** A10 欢迎图、C4 领证合影、C1～C3 寄信 → B 组主角一致性 → A1～A7 场景 → D 组路人 → 其余。前三项是最影响情绪的地方。
