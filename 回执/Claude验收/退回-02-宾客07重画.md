# 退回 02：宾客形象 07 号重画（阿鱼 11/05：滥竽充数）

D1 建卡派给 D3，由 D4 和 D1 判。

## 问题（D3 R1 交的 07 号）
- **脸**：一块平涂的肤色，没有眼睛、眉毛、嘴，看不出表情。01～06、08 都有清楚的五官和神情。
- **头发**：一团灰色的块，没有发丝走向和高光。
- **衣服**：一块绿色，没有扣子、领口、褶皱、明暗。别的宾客都有花纹、配饰、明暗层次。
- **走路帧**：脸上只有一块红斑，身体僵直，侧面和背面都很粗糙。
- 和 01～06、08 放在一起，一眼就能看出不是同一个水平，也不像同一个画师画的。

## 要求
1. 按 01～06、08 的精度重画：
   - 尺寸、头身比、描边要和它们一致。
   - 脸上要有清楚的五官和表情，头发要有层次，衣服要有细节和明暗。
   - 可以有自己的穿搭特征，但不能跟其他七位重复。
2. 走路帧（正面、侧面、背面）都按同样的精度重画，脸在每一帧里都要看得清。
3. 交一张对照图：07 号放在 01～08 中间，原尺寸排一排，下面一排是走路帧。

## 判过标准
- 混在 01～08 里，看不出哪个是新画的。
- 放大 2 倍看：五官、衣服细节、描边，都和别的宾客同一个水平。
