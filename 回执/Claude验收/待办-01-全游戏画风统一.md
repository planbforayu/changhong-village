# 待办 01：全游戏画风统一（阿鱼 11/05）

阿鱼的要求：**画风不要乱跳。** 场景、人物、道具、界面要像同一个画师画的。

D1 建卡，派给 D3 和 D2：
1. **D3 先做风格样板** `回执/W2工位/风格样板.png`，一页里定死下面这些：
   - 星露谷式温暖像素风的调色板
   - 描边的颜色和粗细
   - 像素密度，也就是一个像素放大到多少屏幕像素
   - 字体和字号
   - 对话框、手机、按钮、气泡的边框画法
2. **对照样板全部过一遍**：所有已经做好的图和界面，凡是跟样板不一致的，D3 重画，D2 换上去。
   - 举个例子：第一章群聊那一屏，整片暗红纯色、手机缩在下半屏、字很小，跟场景完全不是一套画风。这类屏都要按样板改。
3. **D4 判**：
   - 所有屏幕截图拼成一张，和样板放在一起比，有一屏跳出来就判不过。
   - 主体要占满屏幕，不留大块空白。
   - 截图不放大，字也能读清。
