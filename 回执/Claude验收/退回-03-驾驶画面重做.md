# 退回 03：上海驾驶画面重做（阿鱼 11/05：瞎画）

D1 建卡，派 D3 画图、D2 接进游戏，D4 和 D1 判。

## 问题
- **路**：是代码画的一块灰色平涂梯形，没有像素质感和纹理，硬贴在背景图上。路一直插进天空，把东方明珠底座和背景里原本的路都盖住了，透视和两边的人行道、栏杆、路灯对不上。整张画面像两张图拼起来的。
- **按钮**：底部三个按钮上只有一个圆点，看不出是干什么用的。车两边的「<」「>」像网页控件，不像游戏里的东西。
- **车**：要对照一览图的 G42 尾部原图（`2 ayu 225 back`），核对车型、颜色、车牌位置是否一致。

## 要求
1. **路要是画面的一部分**：驾驶背景重新画一张，或者整张重做成像素风的道路图，让路面、车道线、人行道、栏杆、路灯在同一个透视里。路要消失在远处的地平线或桥面上，不能插进天空。
   - 路面要有像素纹理：沥青颗粒、车道线的磨损、阴影。
   - 车往前开的感觉，用路面纹理和车道线向下滚动、两边路灯和树往后退来做。
2. **操作直接在画面上**：左右滑动或点屏幕左右两半来换道，不要底部那三个圆点按钮。如果一定要按钮，就画成有方向箭头图标的像素按钮，风格跟风格样板一致。
3. **对面来的车**：用同一画风的像素车，近大远小，跟着路面的透视一起移动。
4. 画风对照 `回执/W2工位/风格样板.png` 和成熟的星露谷式商业游戏截图。

## 判过标准
- 截图里看不出哪里是后贴上去的。路、车、背景是一张完整的画。
- 第一次玩的人不看文字，3 秒内就知道左右滑动能换道。
- 连开 3 次，换道手感顺，撞车有反馈（减速、晃一下、有声音）。
