# R2 停车场十辆车角度内审

十辆车仍按原车位朝北停。观察方向从南向北，车尾在画面下方。请先看原尺寸和 2 倍对照图，重点看后窗、尾灯、后保险杠、后轮下沿和两侧可见宽度。十辆均为独立车身和投影。当前交件只供 Claude 审车图，游戏候选仍使用原车节点。

每辆车按正式停车布局的宽、前后深度与立高制作。原始 rect、立高、PNG 尺寸、绘制原点、排序脚点、影子原点和透明包络均写在 `逐车定位.json`。高度含原向上投影。奇数边界只裁导出的最右列或最末行，原坐标维持精确。所有主体和影子从整数美术网格最近邻 2 倍输出。

跑车、轿跑、轿车、紧凑车和 SUV 分别调整前盖、车顶、后窗与尾部体量。漆色和光向使用 R1 已通过的 51 色，参照阿鱼家暖木、奶油浅色、绿植和正式宴会厅暖红。后灯使用独立红色色阶。车身图和地影各自导出。

- `十车原尺寸与2倍对照.png` 按同一画布原尺寸和最近邻 2 倍排列十辆车。
- `source/draw_cars.py` 从项目停车布局重出全部图件。已冻结的可用颜色见 `source/palette.json`。
- 接入以审定版本的十个车身及影子哈希为准。取得 Claude 角度审定后，再把明确批准的图移入正式场景清单。

在项目根目录运行 `PYTHONDONTWRITEBYTECODE=1 python3 回执/山庄收尾/R2-车辆内审/source/draw_cars.py` 可重建全部审图件。
